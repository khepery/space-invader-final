3. Customize with Your Own Questions

The game ships with a sample bank (50 Money & Banking questions) but works with any subject. You can load your own question set in under a minute.

  1. On the title screen, click ⚙ Settings → 📂 Load My Questions.
  2. Choose a plain text file (.txt) formatted like the sample below.
  3. Your questions appear immediately — pick categories and start the mission.

Question file format

Q: What is the capital of France?
A: London
B: Paris
C: Berlin
D: Madrid
Correct: B
Category: Geography

Q: 7 x 8 = ?
A: 54
B: 56
C: 63
D: 49
Correct: B
Category: Multiplication

Separate questions with a blank line. The Category line is optional. A ready-to-edit template can be downloaded from the game itself (Settings → ⬇ Download Template) or use the included sample file 50 money banking questions for space invaders.txt.

No file? Add questions in the game
Click ⚙ Settings → ➕ Add Manually to type questions directly into the game. Great for quick edits or building a deck live with students.

5. Troubleshooting

The game won't load

  • Confirm purebrainplay.com is not blocked by your school's web filter — ask IT to allow-list the domain.
  • Try a different browser (Chrome works most reliably).
  • Refresh the page; if it still fails, clear browsing data for the site and re-enter the code.

Audio doesn't play

  • Browsers block autoplay until the user clicks. Click anywhere on the title screen — sound will start.
  • Check that your device isn't muted and tab volume isn't 0.

Custom questions didn't load

  • Open the file in a plain text editor (not Word) and verify the Q: / A: / Correct: format matches the sample.
  • Save as .txt with UTF-8 encoding.
